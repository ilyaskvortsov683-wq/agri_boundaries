# aoi — области интереса для `S2_composite.ipynb`

Кладите сюда (на Диске: `Colab_Notebooks/Agro_terra/composite/aoi/`) границы областей в GeoJSON.

- **Имя.** Имя файла без `.geojson` и есть `AOI` в ноутбуке: `TAT.geojson` → `AOI = 'TAT'`.
- **Содержимое.** Любой полигон или мультиполигон в любой системе координат. Если объектов несколько, они объединяются.
- **Субъекты из вашего слоя в GEE.** Их можно выгрузить сюда разом: шаг 2 ноутбука, параметр `GEE_AOI_ASSET`.
- **Свои участки.** Области, которые не совпадают с границами субъектов, рисуйте в QGIS или на geojson.io и сохраняйте
  сюда же.

На Диске уже лежат `TAT.geojson`, `SAM.geojson` и `DON.geojson` (Донецкая область) — копии ваших файлов из папок TAT, SAM, DON.
