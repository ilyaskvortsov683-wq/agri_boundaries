# composite — сезонный композит NDVI Sentinel-2 без Google Earth Engine

`S2_composite.ipynb` — замена GEE-скрипта композита. Он считает **max / min / diff NDVI** (как в GEE) или
**max / min / std NDVI** за период сезона по области интереса. Результат — один GeoTIFF: 3 канала uint8 со значениями
1–255 (0 — нет данных), сжатие JPEG 75 или без потерь.

Снимки берутся из открытого архива Sentinel-2 L2A на AWS (Earth Search, Element84) — по кусочкам, только B4, B8 и SCL.
Для каждого блока выходной сетки сцены накапливаются в родной сетке UTM своего тайла MGRS (max, min, сумма, сумма
квадратов). В выходную сетку переносится только итог, ближайшим соседом, как в GEE. Блоки сохраняются на Диск сразу,
поэтому расчёт продолжается с места остановки.

| файл | что это |
|---|---|
| `S2_composite.ipynb` | ноутбук Colab (собирается из `src/s2_composite.py`: `python3 composite/build_notebook.py`) |
| `aoi/` | границы областей интереса `*.geojson`; на Диске — `Colab_Notebooks/Agro_terra/composite/aoi/` |
| имя результата | `out/<AOI>/composite_<год>_<ММДД>_<ММДД>.tif`, вариант std — `…_std.tif` |

## Проверка на Донбассе

Участок 16×18 км, 2026, 30.04–10.09. Новый композит сравнивался с композитом из GEE того же периода; оба в JPEG 75.

- **Сетка.** Совпадает пиксель в пиксель: EPSG:4326, шаг 8,983·10⁻⁵°, то же начало отсчёта.
- **Каналы max / min / diff.** Корреляция 0,963 / 0,969 / 0,962, среднее расхождение 4,4 / 5,2 / 7,1 из 255.
- **Конвейер v6 (`L_base`) по 301 эталонному полю.** IoU 0,632, IoU≥0,7 0,56, bF 0,707. На композите из GEE: 0,635,
  0,55, 0,706.
- **Классы (засеянное / пар / неиспользуемое).** Пиксельная точность 0,898; на композите из GEE — 0,886.
- **Скорость.** Квадрат 30×30 км считается 80–115 с (12–24 потока); это около 1,5 мин на 1000 км².

## Тонкости, которые учтены

- **Смещение +1000.** В новом архиве `sentinel-2-c1-l2a` в значениях есть смещение +1000 (baseline ≥ 04.00), его надо
  вычесть. В старом `sentinel-2-l2a` оно уже вычтено во всех сценах, хотя флаг `earthsearch:boa_offset_applied` у части
  сцен ошибочно `False`. Оба случая проверены по пикселям.
- **Края полосы съёмки.** Каналы обрезаны по-разному, а маска SCL — 20 м. На краю красный канал ≈ 0 и NDVI ≈ 1, поэтому
  край выкидывается с запасом 3 пикселя, а пиксели с отражением < 0,005 не учитываются.
- **Края облаков и теней.** Маска расширяется на 3 пикселя (`CLOUD_BUFFER_PX`). Это подняло корреляцию канала min с GEE
  с 0,94 до 0,96–0,97.
- **JPEG без YCbCr.** Каналы — не цвета, поэтому сжимаются без цветовой субдискретизации (`PHOTOMETRIC=RGB`): каждый
  канал хранится в полном разрешении. Вне области — 0 и внутренняя маска.
- **Запасной поиск сцен** (`SOURCE='s3'`). Работает без STAC: перечень архива по тайлам MGRS. У границы широтных поясов
  тайл Sentinel-2 носит букву соседнего пояса (37UDP вместо 37TDP), поэтому проверяются обе.
